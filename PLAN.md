# План проекта «Кто кому должен»

## Идея
Компания едет в поездку / идёт в кафе / снимает квартиру. Платят разные люди, в конце никто не помнит, кто кому сколько должен.
Бот живёт в групповом чате: траты вносятся в пару тапов (командой или в Mini App), а в конце бот выдаёт минимальный список переводов:
*«Арман → Роману 4 500₸, Даша → Роману 2 300₸»*.

## Пользовательский сценарий
1. Добавил бота в группу → он закрепляет сообщение с кнопкой «Открыть кошелёк группы».
2. Быстрая трата текстом: `/add 12000 продукты` (по умолчанию поровну на всех).
3. Подробно через Mini App: сумма, кто платил, на кого делить (все / часть / неравные доли), категория.
5. «Рассчитаться» → минимальный набор переводов; получатель жмёт «Получил ✅».
6. Напоминания должникам (отключаемые).

## MVP vs потом
| MVP | Потом |
|---|---|
| Бот в группе: `/add`, `/balance`, `/settle` | Мультивалютность с курсом на дату |
| Mini App: траты, добавление, баланс | Экспорт в Excel, статистика по категориям |
| Делёж поровну / на часть людей | Повторяющиеся траты |
| Минимальные переводы | Telegram Stars — премиум |
| Отметка «долг закрыт» | Личные долги 1-на-1 |
| | Inline-режим `@bot 5000 такси` |

## Принятые решения по механикам
- **Валюта:** одна на группу, выбирается при создании, по умолчанию KZT. Суммы храним в минимальных единицах (тиын). Мультивалюта — потом.
- **`/add` без уточнений** делит поровну на всех зарегистрированных участников группы.
- **Остаток при делении** (1000 на 3): по одной единице, сначала плательщику (если он в доле), потом остальным по порядку → 334/333/333.
- **Редактировать и удалять траты** может любой участник группы; все изменения пишутся в историю.
- **Участники — только реальные пользователи Telegram** (нажал «Я в деле 🙋», написал боту команду или открыл Mini App). «Призрачных» участников по имени нет.
- **Вышел из чата** → остаётся в расчётах с пометкой «вышел», пока его баланс не станет нулевым; в новые траты по умолчанию не попадает.
- **Закрытие долга:** должник жмёт «Я перевёл» (или `/paid 3000 @user` — можно частично), получатель подтверждает «Получил ✅» или отклоняет. В балансе учитываются только подтверждённые переводы.
- **Реквизиты:** указываются в личке с ботом (кнопка «💳 Мой номер для переводов» в группе ведёт туда): «📱 Взять номер из профиля» (Telegram отдаёт номер одной кнопкой, принимаем только свой контакт) или «✏️ Ввести вручную», если карта на другом номере. В `/settle` у каждого перевода кнопка «Скопировать». Оплата должна занимать минимум тапов.
- **Категории:** фиксированный системный список + группа может добавлять свои. Для `/add 12000 продукты` категория угадывается по ключевым словам.
- **Одна Telegram-группа = один кошелёк** (без отдельных «событий» внутри группы).
- **Языки:** русский и английский; язык группы определяется по тому, кто добавил бота, меняется командой `/lang`.
- **Mini App — делёж:** поровну на выбранных (галочки) или точными суммами (сумма долей = итог). Долей/процентов нет.
- **Mini App — вход:** из группы — сразу её экран (ссылка `t.me/<bot>/<app>?startapp=g_<public_id>`, public_id случайный); из профиля бота — список своих групп с балансом, если групп нет — инструкция «добавь бота в группу».
- **Вступление через Mini App** проверяется через `getChatMember`: ссылку могли переслать постороннему.
- **Действия в Mini App видны в чате:** бот пишет о добавлении и удалении трат и о переводах (об изменениях — нет, они в истории траты); подтверждение перевода в приложении обновляет сообщение в чате.
- **Дата траты** — момент добавления, выбора даты нет.
- **Напоминания должникам:** в личку (кто не открывал личку с ботом — одной сводкой в группе), по умолчанию раз в неделю в 19:00 по Алматы; в Mini App: выкл / раз в 3 дня / раз в неделю, менять может любой участник. Ручной кнопки «Напомнить» нет. Переводы, ждущие подтверждения, не напоминаем.
- **Экспорт в Excel:** бот присылает .xlsx в личку (команда `/export` в группе или кнопка в Mini App).
- **Общий котёл** — без отдельной фичи: все отмечают перевод тому, кто собирает (`/paid` или «Я перевёл»), он подтверждает, а траты из котла вносит как плательщик.

## Архитектура
```
Telegram ──► Bot (aiogram 3) ──┐
                               ├──► FastAPI ──► PostgreSQL
Mini App (WebView в TG) ──────┘        │
                                       ├──► Redis (кэш, очередь)
                                       └──► Worker (arq) — напоминания
```

## Модель данных
```
users          id, tg_id, name, username, language, payment_details?
groups         id, tg_chat_id, title, currency, language
group_members  group_id, user_id, joined_at, left_at?
categories     id, group_id? (NULL = системная), code?, name, emoji
expenses       id, group_id, payer_id, amount, title, category_id, created_by, created_at, deleted_at?, version
expense_shares expense_id, user_id, amount
expense_history id, expense_id, user_id, action, snapshot (json), created_at
settlements    id, group_id, from_user, to_user, amount, status (pending/confirmed/rejected), created_at, resolved_at?
```

## Ключевые технические задачи
1. **Минимальные переводы.** Считаем чистый баланс каждого (заплатил − должен). Жадно: крупнейший должник платит крупнейшему кредитору, пока все не ноль → не больше n−1 переводов. (Строгий минимум — NP-трудная задача.) Покрыть тестами.
2. ~~**Распознавание чеков.**~~ Отказались (2026-10-01): фича не понравилась, делёж по позициям не нужен — хватает «поровну на выбранных» и точных сумм.
   - Обработка в фоне через очередь, бот обновляет сообщение «Распознаю…».
3. **Безопасность Mini App.** Проверка HMAC-подписи `initData`, `user_id` только оттуда.
4. **Нюансы Telegram.** См. CLAUDE.md.
5. **Конкурентность.** Одновременное редактирование траты → транзакции + оптимистичная блокировка (`version`).

## Конкуренты и отличие
- Splitwise / Tricount — отдельное приложение, надо ставить и регистрироваться всем.
- Telegram-боты-сплиттеры — в основном текстовые, без UI.
- **Отличие:** ничего не устанавливать, всё в чате компании; удобный Mini App; минимум переводов с подтверждением и копированием реквизитов в один тап.

## Монетизация (опционально)
Бесплатно — базовое. Премиум за Telegram Stars: мультивалюта, экспорт, статистика по категориям.
